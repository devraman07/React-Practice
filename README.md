# React Basics 🚀

A collection of **10 beginner-friendly React projects** built while learning the fundamentals of React — components, hooks, state management, forms, API calls, and conditional rendering.

Each project lives in its own folder and focuses on a specific concept, making it easy to follow along and reference individual patterns.

## ⚡ Getting Started

Follow these steps to run any project locally:

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/react-basics.git
cd react-basics
```

### 2. Navigate to a project folder
```bash
cd <project-folder-name>
```

### 3. Install dependencies
```bash
npm install
```

### 4. Run the development server
```bash
npm run dev
```

The app should now be running at `http://localhost:5173` (or the port shown in your terminal).

## 🎯 Learning Outcomes

By building these projects, this repo covers core React fundamentals including:

- Managing local state with `useState`
- Handling side effects with `useEffect`
- Fetching and displaying data from an external API
- Building and validating controlled forms
- Conditional rendering techniques
- Working with arrays and objects in state (`map`, `filter`, `sort`)
- Component composition and reusability
- Basic UI/UX patterns (toggles, accordions, sliders, filters)
